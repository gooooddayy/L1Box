通用前置（做之前先备好）

  • 装最新包：文件名以 ad 结尾（含旋转按钮连点延寿）。若装的是旧包，以下现象可能与本文不符。
  • 备一部 多集剧（至少 3 集）——测续播、连播、片头片尾。
  • 备一集 短视频（10 分钟以内）——测缓冲灰条，长片会看不出在动。
  • 每项检查前先 按返回退出播放页再重进，避免上一项的状态残留互相干扰。
  • 全程看着有无 闪退；任何一项异常都先记下现象再继续下一项。

如果某一项没过，按这个格式发我

  1. 是哪个功能（第几项）
  2. 机型 + 安卓版本
  3. 做到第几步出的问题
  4. 看到的现象 / 期望的现象
  5. 能截图或录屏最好，没有也行
