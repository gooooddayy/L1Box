## 二、改了什么（逐文件）

### 1. `player_vod_control_view.xml` — 新增「外部」按钮

在**解析档 `play_ijk`（硬解码/软解码）右侧**插入 `play_ext`，文案「外部」，样式与相邻按钮完全一致。
容器是 `HorizontalScrollView`，加一项不会挤爆布局（最多需要横滑）。

### 2. `VodController.java` — 长按 → 外部按钮

- **删除** `mPlayerBtn.setOnLongClickListener(...)` 整段（原 521–579 行）。
- **新增** `mPlayerExtBtn.setOnClickListener`：弹出 `SelectDialog`，数据源＝`PlayerHelper.getExternalPlayerItems()`。
  - 选**外部**播放器 → `applyPlayerItem(pl=10..14)` + `updatePlayerCfg()` + `replay(false)` → 走**已有的**吊起路径（`PlayFragment.startPlayUrl` 里 `pl >= 10` 分支），吊起失败会自动退回内置继续播。
  - 选**系统播放器** → `applyPlayerItem(pl=0)` + 重播，在本页内换内核。
- `updatePlayerCfgView()` 由包级私有改为 **public**（详情页切内核后要同步控制条按钮文案）。
- 清气泡：`mLandscapePortraitBtn`（旋转）、`mCastBtn`（投屏）。

### 3. `PlayerHelper.java` — 清单方法替换

- **删除** `getAllPlayerItems()`（＝内置三项 + 系统 + 外部）。长按取消后它已无调用点。
- **新增** `getExternalPlayerItems()`：`[系统播放器(0)]` + 已安装的外部（10~14）。
  - 判据完全由"本机有没有"决定：装了就列出、没装就不列；缺省至少有一项，**调用方不必判空**。
- 清单**不做静态缓存**（第八批已改），装完外部播放器无需重启 App。

### 4. `DetailActivity.java` + `activity_detail.xml` — 详情页外部播放

- 布局：投屏按钮 `tvCast` **左侧**新增 `tvExtPlayer`（36dp、与投屏同款 `app:tint`、padding 7dp）。
- 新图标 `res/drawable/ic_open_external.xml`：方框 + 右上出框箭头（Material `open_in_new` 语义＝"用其他应用打开"），与 `ic_cast` 同属线性图标，风格统一不突兀。
- 逻辑 `showExternalPlayDialog()`：
  - 前置条件与投屏一致（预览播放器存在且地址非空），否则提示「请先播放视频后再使用外部播放器」。
  - 地址复用 `playFragment.getFinalUrl()`、**请求头复用播放中那一份**、进度复用 `getSavedProgressOfCurrent()` ⇒ **全程零新增网络请求**。
  - 选外部 → `PlayerHelper.runExternalPlayer(...)`，成功后**暂停预览**（避免与第三方播放器同时出声）；失败如实提示。
  - 选系统播放器 → `playFragment.switchPlayerItem(0)`：切内核并重播。
- 清气泡：`tvCast`、`tvDownload`、`tvExtPlayer`。

### 5. `PlayFragment.java` — 对外接口（详情页要用）

| 新方法 | 作用 |
|---|---|
| `public boolean switchPlayerItem(int)` | 切内核 + 同步 `mVodInfo.playerCfg` + 通知控制条刷新 + 重播 |
| `public HashMap<String,String> getPlayingHeaders()` | 请求头可读（**复用 `mPlayingHeaders`，不新造机制**） |
| `public long getSavedProgressOfCurrent()` | 当前集已存进度（吊起时续播） |
| `public void pausePlayback()` | 吊起成功后暂停内置播放 |

### 6. 气泡全清（8 处，只清 tooltip）

来源：Android 8.0 起 View 的 tooltip **默认取 `contentDescription`**；底部导航两项则由 Material 的 `NavigationBarItemView` 自动用菜单标题设置。

新增 `Utils.disableTooltip(View)`：**只把 tooltip 置空**，保留 `contentDescription`（无障碍语义不变），也不动任何长按原有行为；API < 26 直接跳过（低版本本就没有 tooltip 机制）。

| 位置 | 控件 |
|---|---|
| 底部导航 | 「首页」「我的」（`MainActivity.post` 里遍历子 View，视图建好后才清） |
| 播放控制条 | 旋转、投屏 |
| 详情页 | 投屏、下载、外部播放 |
| 订阅列表项 | 「更多操作」（`item_subscription`，每次绑定清一遍，防列表复用） |
| 分享弹窗 | 二维码 |

### 7. `AndroidManifest.xml` — 包可见性补齐

`<queries>` 原**只声明了 IDM**。Android 11+ 未声明的包连 `getApplicationInfo` 都查不到（＝装了也检测不到、列表里不出现）。补齐 MX(pro/ad)、Reex、Kodi、VLC 五个包名，与代码里的识别清单一一对应。
「附近TVBox」走局域网 HTTP 推送、不是按包名吊起，**不需要**声明。

## 四、边界与遗留

1. **外部播放器"吊起成功但实际没播"我们感知不到** —— Intent 发出去了就算成功。这是所有 TVBox 系应用的共同边界。
2. **系统播放器能力最弱**（安卓自带 MediaPlayer，HLS 大多不支持）。它是"可选"而非默认，不影响任何自动路径；详情页选它＝在预览小窗里换内核重播。
3. **详情页的外部播放仍要求"当前有在播的视频"** —— 与投屏按钮同一前置条件（地址来自预览播放器的最终地址）。
4. **本地视频链仍未删**（用户口径："宁愿先保留"）。`VideoListActivity` 全工程无启动点，其播放页只由它启动 ⇒ 整条链事实不可达。`VideoInfo` 被 `PlayService` 等 7 处引用，牵连面比看上去大，本轮零删除。
5. **旋转开关仍未碰** —— 全工程无 `WRITE_SETTINGS` 权限、无 `Settings.System` 调用，我们改不了它；只读读到 `accelerometer_rotation=0`。
