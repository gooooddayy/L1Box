## 一、你问的 5 件事

### 1.1 手机旋转开关 —— 不是我们改的系统设置，但我们的页面会"主动定方向"

| 查什么 | 结果 |
|---|---|
| 有没有读写系统旋转设置 | **没有**。全工程搜不到 `Settings.System` / `ACCELEROMETER_ROTATION` |
| 有没有 `WRITE_SETTINGS` 权限 | **没有**（manifest 里 9 条权限全列过，不含它）⇒ 我们**根本没有能力**去改你手机的旋转开关 |
| 有没有主动定方向 | **有，共 3 处**：① 播放页进全屏 `setRequestedOrientation(LANDSCAPE)`（`VodController:765`、`PlayFragment.changedLandscape`）② 播放页"旋转"按钮点击循环 4 档（横屏→反向横屏→竖屏→反向竖屏，`VodController:776`）③ 本地播放页在 manifest 里写死 `screenOrientation="landscape"` |

**可能的解释**：Android 12 以上，当应用锁定了方向，系统的"自动旋转"开关**显示状态**会跟着变（系统的联动行为，不是我们写设置）。所以你在播放视频时会看到下拉里的旋转开关"变了"。

**需要你确认（二选一）**：
- 是**下拉快捷开关里的"自动旋转"**自己变状态？（→ 系统联动，属正常）
- 还是**系统设置里**的开关被改了？（→ 那基本不可能是我们，我们没权限）

另外请顺带说一句：是**自己变开**还是**自己变关**？我按现象决定要不要动（比如把"记住方向"去掉）。

### 1.2 首页/设置按钮的悬浮提示 —— 已定位：Material 组件自带的**长按气泡**

反编译 `classes2.dex` 实证：Material 1.4.0 的 `NavigationBarItemView.initialize()` 里会调用
`TooltipCompat.setTooltipText(this, 标题)`；Android 14 上系统的长按 tooltip 就会弹出一个灰底小气泡。
气泡文本 = 那一项的标题。

**能弹气泡的控件清单（全工程只有这些写了无障碍描述/标题）**：

| 位置 | 控件 | 气泡内容 |
|---|---|---|
| 底部导航 | 「首页」项 | 首页 |
| 底部导航 | 「我的」项（你说它叫"设置"） | 我的 |
| 播放页 | 旋转按钮 | 旋转 |
| 播放页 | 投屏按钮 | 投屏 |
| 详情页 | 投屏按钮 | 投屏 |
| 详情页 | 下载按钮 | 下载 |

**取消方案**：遍历这些控件清掉 tooltip（`TooltipCompat.setTooltipText(v, null)`）。
底部导航要在**每次切换 tab 后补清一次**（Material 会重建 item view）。
**只清气泡，不动任何功能**（长按旋转按钮锁定、长按投屏等原有行为全保留）。

**我建议一次全清**（不然过几天你在别处又看到一个）。你也可以只清底部导航那两处。

## 二、需求一：播放器按钮改造

### 2.1 现在的实际行为（源码出处）

播放页底部控制条（`player_vod_control_view.xml` 顺序）：

```
[重播] [刷新] [16:9] [x1.0] [播放器:系统] [硬解码] [片头/片尾] [字幕] [音轨] [横竖屏]
                          ↑ play_player        ↑ play_ijk（仅 IJK 播放器时显示，Exo 下隐藏）
```

- **短按**「播放器」= 在内置三档循环 `Exo → IJK硬解 → IJK软解 → Exo`（`VodController` 短按分支）
- **长按**「播放器」= 弹完整列表（内置三项 + 系统 + 已装外部）（`VodController` 长按分支，用 `SelectDialog`）

### 2.2 你要的改法（我的理解，请确认）

1. 「播放器」按钮 **点击 = 直接弹播放器列表**（含外部），选完即切换并重播；
2. 按钮位置 **移到"解析档"右边**；
3. 详情页投屏按钮左边 **加一个"外部播放器播放"按钮**。

### 2.3 需要你先确认的 3 点

| # | 问题 | 我的理解 / 选项 |
|---|---|---|
| Q1 | 你说的**"解析档"**是指哪个？ | 我理解 = 控制条里的 **「硬解码/软解码」按钮**（它在 Exo 播放器下是隐藏的，只有 IJK 时出现）。如果你指的是**详情页的"解析"线路那一排**，请指正 |
| Q2 | 短按循环**要不要保留**？ | A：全取消，点击只弹列表（最简）<br>B：点击弹列表，另加一个独立"外部"按钮专开外部（两键） |
| Q3 | 列表内容 | 内置三项（Exo/IJK硬/IJK软）+ 系统 + 已装外部，与现在的长按菜单一致？ |

### 2.4 位置示意（按 Q1 理解为"硬解码"）

```
现状：  [重播] [刷新] [16:9] [x1.0] [播放器] [硬解码] ...
```

## 三、需求二：详情页「投屏」左边加「外部播放器播放」

### 3.1 位置

详情页顶部那一排：`[来源胶囊] ———— [投屏] [私密浏览]`
改为：`[来源胶囊] ———— [外部播放] [投屏] [私密浏览]`

### 3.2 地址从哪来（这是关键，决定好不好做）

详情页本身**内嵌了一个预览播放器**（`PlayFragment`，`SHOW_PREVIEW` 默认开），投屏按钮就是取它的地址：

```java
// DetailActivity.java:196
String url = getCurrentVodUrl();   // = playFragment.getFinalUrl()
```

所以「外部播放」按钮**同样取这个地址**，不需要额外的取链逻辑 —— 你选中哪一集、它就是哪一集的地址。

### 3.3 行为设计

| 情形 | 表现 |
|---|---|
| 有地址 + 装了外部播放器 | 弹「选择外部播放器」列表（只列已装外部：MX/Reex/Kodi/附近TVBox/VLC）→ 选中即吊起；**同时暂停页面自带的预览播放**（避免两个同时出声） |
| 有地址 + 一个外部都没装 | 提示"未检测到外部播放器"（按钮不做隐藏，避免布局跳动） |
| 没地址（还没选剧集 / 预览被关） | 提示"请先选择剧集播放" |
| 地址是本地代理（127.0.0.1） | **允许**（外部播放器在同一台手机上，能播 127.0.0.1；这点跟投屏不同，投屏才不行） |
| 吊起失败 | 提示"调用失败"（详情页没有内置播放动作，不做回退） |

### 3.4 一个必要的小配套

外部播放器要能播需要请求头（Referer/UA）。详情页现在只拿得到地址，拿不到请求头（请求头在 `PlayFragment` 内部生成）。
需要给 `PlayFragment` **加一个取请求头的方法**（复用已有的 `fillMissingHeaders`，不新增请求、不改行为）。

## 六、影响面与风险

- 以上全部是 **UI 交互层改动**：不碰取链、不碰播放内核、不碰源站请求 → 对"能播不能播"零影响。
- 播放页「播放器」按钮改点击弹列表：**与现在长按弹出的列表完全同一份数据**，只是入口从"长按"变"点击"。
- 详情页「外部播放」是**纯新增按钮**，投屏那条路一行不改。
- 唯一"动到已有逻辑"的是气泡清理（清 tooltip），**不动任何点击/长按行为**。
