## 一、结论：三条口径（这就是"同步"）

| # | 动作 | 作用范围 | 是否落盘 | 优先级 |
|---|---|---|---|---|
| 1 | 设置页改「默认播放器 / IJK 解码」 | **本片本线路没有手动选过播放器**的情形（含没看过的、看过的、所有线路） | 全局 Hawk | 缺省值，最低 |
| 2 | 播放页 / 详情页手动切内置内核（系统 / Exo / IJK硬 / IJK软） | **本片·本线路的所有集**（换线路互不影响） | 本片历史（按线路存档） | 覆盖口径 1 |
| 3 | 外部播放器（MX / Reex / Kodi / VLC / 附近TVBox） | **仅本次这一集** | **不落盘** | 不参与 |

- 口径 3 吊起后，本线路配置原样保留；下次进入回到该配置（没手动切过时＝设置页默认）。
- 播放页与详情页共用同一份清单、同一套落盘规则 —— 两处选外部都是"仅本次"，两处选内置都是"本线路生效"。

## 二、为什么必须加一个标记（当前冲突点拆解）

现状用「`playerCfg` 里有没有 `pl` 键」来判断要不要吃默认值，这个判据是坏的：

| 现象 | 根因 |
|---|---|
| 改设置页默认播放器，对看过的片子不生效 | `pl` 一旦写进 cfg 就永久固化，`initPlayerCfg` 的"补默认值"分支不再触发 |
| 用户根本没切过播放器，只是调了下比例/速度，这片子也永远跟死默认值 | 控制条**任何**按钮（比例 `sc`／速度 `sp`／起播跳转 `st/et`）都会走 `updatePlayerCfg()` → 把整份 cfg（含 `pl`）写回历史 |
| 订阅里某站点配的默认播放器（`SourceBean.playerType`）被永久压住 | 同上，`pl` 存在即不再重取站点默认 |
| 换线路后播放器选择跟着走 | `playerCfg` 是影视级单份，不含线路维度 |

**解法：把"用户有没有手动选过播放器"显式记下来，不再靠字段有无推断。**

- 配置里新增键 `plt`（player type touched）：只有**用户手动选播放器**才写 `plt=1`。
- **不置 `plt`** 的写入路径：比例 / 速度 / 起播跳转时间、以及**自动兜底** `switchToNextInternalPlayer()`（自动换内核绝不能被当成用户选择固化下来）。
- 进播放页时：`plt != 1` → 重新取默认覆盖 `pl` 与 `ijk`；`plt == 1` → 保留用户选择。

这样"调过比例但没切过播放器"的片子，仍然跟随设置页默认 —— 正是你要的"没切换过播放器的先确定不冲突"。

## 三、数据模型改动（唯一真相 = 按线路存档）

| 项 | 内容 |
|---|---|
| 新增 | `VodInfo.flagPlayerCfgMap`：`线路名(playFlag) → 该线路配置 json` |
| 序列化 | `RoomDataManger` 的排除策略只排除 `seriesFlags`/`seriesMap`，新 map 自动进历史 ⇒ **跨重启保留** |
| 保留 | `VodInfo.playerCfg` 字段不动，语义改为"当前线路配置的快照"，兼容全工程现有读点 |
| 读取顺序 | ① `map[当前线路]` → ② 旧数据回退读 `playerCfg` → ③ 全新构造（站点默认优先，其次 Hawk） |

**挂载点为什么干净**：`playFragment.setData()` 全工程只有一处调用（`DetailActivity.jumpToPlay():499`），换线路（`chooseFlag`→`chooseSeries`）与换集都会经过它 ⇒ 只要 `initPlayerCfg()` 按 `mVodInfo.playFlag` 取存档，线路级作用域自动成立，**不需要改换线路逻辑本身**。

**旧数据（已装机用户的历史记录）兼容 —— 不确定就保持原样**：

| 旧 cfg 状态 | 判定 | 处理 |
|---|---|---|
| 没有 cfg（没看过） | 没切过 | 用默认 |
| `pl` 与当前默认一致（或与站点默认一致） | 视为没切过 | 用默认刷新（用户感知不到差异） |
| `pl` 与默认不一致 | 视为手动切过 | 认领为该线路存档 + `plt=1`，保持原样，不冲掉 |

## 六、验收判据

**闸门**（语义断言，预计 361 → 约 372）：

1. 播放页选外部播放器**不得**写配置、不得触发重播；
2. `plt` 只能由"用户手动选播放器"的入口写入，自动兜底与比例/速度写入不得置它；
3. `initPlayerCfg` 必须按线路取存档（不得只读影视级那一份）。

**真机（4 步，缺一不可）**：

| 步骤 | 操作 | 期望 |
|---|---|---|
| A 默认跟随 | 新片播一集 → 只调比例 → 退出重进 → 设置页默认改 IJK → 再进该片 | 走 IJK（没切过播放器就听默认） |
| B 线路级 | 线路1 手动切 IJK软 → 看几集 → 切线路2 → 再切回线路1 | 线路2 用默认，线路1 回到 IJK软 |
| C 外部仅本次 | 播放页外部 → 选 MX | 本集走 MX；弹窗"当前"仍显示原配置；换下一集回到原配置 |
| D 跨重启 | B 之后杀进程重进 | 线路1 仍是 IJK软 |

**不回归**：起播率口径不变（≥95%）、看门狗 0 判死、崩溃 0。

## 七、明确不做

- 不做自动换线路、不把外部播放器放进自动兜底链（沿用已否决口径）。
- 不加"恢复默认播放器"按钮（如后续需要再加）。
- 不动换线路/选集逻辑本身，只让配置按线路分开。
- 不动控制条按钮布局与排布。
