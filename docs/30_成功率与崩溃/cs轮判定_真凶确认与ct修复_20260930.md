## 四、ct 修复：自研惯性，绕开它

**思路**：`onFling` 返回 **true 劫持**，不让系统再起 fling，改用**真实时钟 + 指数衰减**自己驱动。

```kotlin
private val l1OwnFling = true      // ← 回退开关（改 false 即回到系统行为）
private val l1FlingTauMs = 420.0   // 衰减时间常数：总距离 ≈ v0 × TAU
private val l1FlingMinV = 60.0     // 速度低于此值即停（px/s）

// 每帧：v(t) = v0 · e^(−t/TAU)  →  dy = v · dt
// ① 绕开 smoothScrollBy（系统 fling 不再启动）
// ② 不受 animator_duration_scale 影响（实测 0.5x 也会让惯性短约 20%）
```

**四个安全设计：**

| 设计 | 原因 |
|---|---|
| **用户按下立即停**（`endOwnFling("用户按下")`） | 否则自研惯性会与手指拖动**叠加** |
| **`offset` 不再变化即停**（撞界） | `RecyclerView.scrollBy` 会钳制，不会越界；不检测会空转 |
| **`dt` 夹在 [1,50] ms** | 防止掉帧/被抢占时一帧跳太远 |
| **带回退开关** `l1OwnFling = false` | 万一手感不对，一行即可回到系统行为 |

**埋点**：`[tp] ★右栏自研fling[结束]：原因=… 帧=… 位移=… 初速=… 时长=…ms`
⇒ 可直接与 cs 的「恒定序列」对照，确认已生效。
