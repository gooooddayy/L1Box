### ② 交付 `应用推广渠道与曝光策略_20261008.md`（核心结论）
**制度现实（最重要的一条）**：
- 国内应用商店**基本不可能上** —— 视听类 App 需《信息网络传播视听节目许可证》
- ⭐ **定位决定命运**：定位成「**本地视频播放器**」（NOVA / VLC 类）⇒ 商店**可以上**；
  定位成「**影视聚合 / 在线播放**」⇒ **上不了**。我们现在 README/Description 写的是"影视播放器"
  ⇒ 商店审核会按后者理解 ⇒ **"上架商店"与"触达影视用户"只能选一个**（比任何推广技巧都关键）
- ⇒ **这个品类在国内没有"合法的大规模公开推广渠道"**，传播天然依赖非正规渠道

**三阶段路径**：
| 阶段 | 动作 |
|---|---|
| 一（零风险） | GitHub 优化 ✓已完成 → **F-Droid 提交**（条件基本满足：公开✓ / AGPL✓ / 无广告✓ / 有 tag✓） → **README 加截图·GIF** → 保持发版节奏 |
| 二（1~3 月） | APKPure / APKMirror 提交、酷安、Reddit（r/androidapps、r/fossdroid、r/opensource） |
| 三（风险自负） | 垂直社区（影视论坛/群）—— 曝光效率最高，但直接招投诉与下架 |

**内功 ＞ 渠道**：README 截图/GIF（**转化率第一因素**：看不到界面就不会下载；⚠️ 截图不得出现真实影视海报）、
Release 说明写清楚、更新节奏、App 内"关于"页放仓库地址、版本号语义化、Issues 及时回几条。

**不要做**：买量刷量（风控识别反降权）、在影视资源语境推广、**承诺"有源/能看什么"**
（一旦承诺，责任就从"使用者自配"转移到作者身上）。
**规模 ＝ 风险**：小范围开源传播可控；大规模营销 ⇒ 投诉/下架/律师函概率显著上升。

**判据（`PlayFragment.showResumeTip`，474~487 行）** —— 跳转提示要出现必须**同时**满足三条：
1. `progressKey != mResumeTipShownKey`（本会话内该集没提示过）
2. **`rec > skipSec * 1000`（历史进度 > 配置的"跳过片头"秒数）** ← **主因**
3. `rec >= 10000`（历史进度 ≥ 10 秒）

⇒ 不出现的情形：
- **配了"跳过片头 90 秒"，上次只看到 80 秒** ⇒ 条件2 不满足 ⇒ 不弹跳转（改为弹 Toast「已跳过片头 90 秒」）
