## 播放器「刷新」按钮需求分析 + 设置项答疑（16:35，**未动代码，等用户拍板**）

### ① 「刷新」按钮现状（代码实况）
- 「刷新」= 播放设置弹窗 `PlayingControlDialog` 的 `refresh` 按钮 → `mPlayRefresh` → `listener.replay(false)` → `play(false)`；「重播」= `replay(true)`，**会清 ProgressStore+字幕缓存**（从头播，设计本意）。
- 刷新现状：**不清进度**、重新取链起播，但**不自动跳回**——2026-09-24 定的「历史进度不自动跳、改弹『点击跳转』」+ 提示按 `mResumeTipShownKey` 每集只弹一次（刷新不重置）⇒ 本集之前弹过的话，刷新后连提示都没有、直接从 0 播（比"点一下"更糟）。
- **用户要的语义**：刷新 = 重载 + **自动**跳回点击时位置（现在没有）。
- **方案 A（推荐）**：`replay(false)` 里取点击瞬间位置（`getCurrentPosition()`，兜底进度库）+ 置标志；`getSavedProgress()` 钩子命中标志时返回"上一位置"⇒ 内核 `startPlay()`（VideoView:214）自动 seek，时机天然正确；起播成功清标志 + 抑制「点击跳转」提示。不动重播/正常进入/换集/兜底链。
- **方案 B**：`playing()` 里显式 seekTo——要自管时序，不推荐。
- **待拍板**：①<10 秒跳不跳（现有提示规则 <10s 不弹；刷新建议降到 >3s 或 >0）②要不要轻提示「已回到 xx:xx」。
- 关键代码位：`PlayingControlDialog.java`（弹窗）、`PlayFragment.replay()` 603、`play(false)` 2417、`showResumeTip()` 479、`getSavedProgress` 匿名类 ~536、`VodController.mPlayRefresh` 470、`VideoView.startPlay()` 214（内核取进度时刻）。

### ② 缓存默认值（答复）
- **IJK 缓存默认关闭**（`IJK_CACHE_PLAY=false`）：只对 IJK 内核 + 直链文件（mp4/mkv/avi，**不含 m3u8**），落盘 `/ijkcaches/`，单文件上限 60MB。影视源多为 m3u8 ⇒ 保持关闭。
- **磁盘缓存（Exo）默认开启**（`EXO_DISK_CACHE=true`）：`ExoCacheConfig`，目录 `exo-video-cache`，**上限 256MB LRU 自动淘汰**，HLS 分片也缓存；启动时自动清旧缓存。保持开启。

### ③ 安全DNS（答复）
- 选项仅 4 个：关闭/腾讯 doh.pub/阿里 dns.alidns.com/360 doh.360.cn；**出厂默认=腾讯（1）**；老用户自动迁移一次，手动选过就永久尊重（DOH_USER_SET）。
- 作用：防 DNS 劫持/污染；两条链路 = OkHttp（搜索/取链/图片）+ IJK 播放（本机 `/dns-query` 端点转发，`native_setDot`）。
- 兜底：失败自动回退系统 DNS（2s）、私有地址绕开、连败 3 次熔断 5 分钟 ⇒ 默认开着风险≈0。建议保持「腾讯」。
- 代码位：`OkGoHelper`（dnsHttpsList/getDohUrl/DEFAULT_DOH=1）、`App.upgradeDohDefault()`、`L1FallbackDns`、`L1DnsPolicy`、`RemoteServer` /dns-query、`ControlManager:77` setDotPort。
