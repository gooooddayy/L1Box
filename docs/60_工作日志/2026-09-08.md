## 搜索闪退根因定位与修复（20260908f）
- adb logcat 抓到真凶：SIGABRT/SIGSEGV，Abort message "JNI DETECTED ERROR: obj == null in CallObjectMethod from DexNative.getSpider"
- 根因：Guard 加固 jar(wexguard so+加密payload)的 DexNative.getLoader 对 L1Box 返回 null（疑似宿主签名白名单校验不过），静态内部 loader=null，任何 Guard 站点(如 WexAppV7Guard)创建实例时原生层 abort 杀进程，Java 层不可捕获
- 反编译确认：BaseSpiderGuard.<init> -> Init.getSpider(String) -> DexNative.getSpider(loader,cls)，loader 为静态 DexClassLoader 字段
- 修复：JarLoader.getSpider 创建前检查 Guard jar 内部静态 DexClassLoader 是否就绪（按 classloader 缓存结果），未就绪降级 SpiderNull 跳过该 jar 全部站点；普通 jar 无 DexNative 直接放行
- 产物 20260908f 已 adb install 到设备 <设备序列号>；e 版已归档
- 附带发现：日志中有另一坏 jar（0b9565...jar 非法 zip，下载到坏包），仅产生 SpiderNull 不崩溃
