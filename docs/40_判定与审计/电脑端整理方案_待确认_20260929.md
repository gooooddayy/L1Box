## 四、会话瘦身：228 MB → 预计 60~70 MB

09-19 你做过一次（273→65 MB，-76%），方法已验证。**这次同样可以安全做。**

**原理**：jsonl 是 `id`/`parentId` 串成的事件流。
**铁律 = 只截超长字段，绝不删行**（删行会断链；截字段则链天然完整）。
体积全在机器噪声里（`function_call_result` 双份、`file-history-snapshot`、`providerData.reasoning`），真对话只占约 7%。

**现成工具**：`_tools/session_prune.py`（改开头两个常量即可指向本会话）

**安全保障**：
1. 先 gzip 备份
2. 变换后自检（断链数 / 解析失败数不为 0 就中止）
3. 就地覆盖（保留同一 inode，兼容程序持有的写句柄）
4. 复核体积、NUL 字节 0、末行可解析

> ⚠️ 效果要**重开 WorkBuddy** 才体感得到。
