## 三、App 自身缓存（101 MB）—— **建议保留**

```
/sdcard/Android/data/com.github.tvbox.osc/cache/exo-video-cache/     ← 101 MB
```

这是 gd 版起就有的**播放缓存**（缓存看过的视频分片，回看同一集会秒开）。

**为什么建议留着**：App 自己已经有一套"冷启动清缓存"逻辑 —— **软件内退出再进入保留缓存（能命中），完全退出软件才清**（见 `App.java` 里 `ExoCacheConfig.purgeStaleOnProcessStart`）。也就是说这 101 MB 会自己维持在合理范围，不需要手动管。

真想清，**在 App 里点设置里的「清理播放缓存」**比删目录更安全（避免与正在播放的 SimpleCache 争同一目录）。

### 连带子目录一起清

若确认 `l1_old/` 整个都要（里面 5 个文件全是日志），可直接删 `l1_old/` 这个**文件夹**。

### 判断标准（万一以后又攒起来）

> `/data/local/tmp/` 下：**`.log` 结尾的 + `br.apk`** = 可删；
> **目录名 `dalvik-cache` / `scene-daemon` / `toolkit` 与 `binder.so` / `input_devices`** = 别碰。
