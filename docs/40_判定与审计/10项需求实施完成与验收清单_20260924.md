## 四、装机验收清单（需要你做）

设备当前未连接（`adb devices` 为空）。插线后建议按此顺序走一遍：

**0. 先确认真机装的是新包**（避免验了半天旧包）
```
adb shell pm path com.github.tvbox.osc
adb pull <上一步输出的路径> base.apk
certutil -hashfile base.apk MD5
```
MD5 应为 `226d6ecd5fc757db080cee4b48af4027`。

**1. 冷启动 + 立刻点搜索（#2 主场景）** —— 这是本轮最重要的一条
- 期望：**不再是"暂无数据"**；先转圈，约 2 s 出现「正在初始化播放源，请稍候…」；若播放源还没加载完，20 s 后转圈文案变「播放源仍在加载，请稍候…」，**继续等而不是给空态**；池一就绪即自动出结果。
- 对照：旧版 bq 在这个场景会直接给"暂无数据"。

**2. 真的没有结果时（#2 诚实空态）** —— 用一个生僻词搜
- 期望：**只有**在"池已定论＋站点问全了＋池签名没变＋结果确为 0"四条同时成立时才显示空态；任一不成立就继续等。

**3. 播放源地址失效时（#2 订阅失败态）** —— 临时改一个不可达的订阅地址
- 期望：单独提示订阅加载失败（不是"暂无数据"），并**同址重拉 1 次**；本次启动内不再重复重拉。**不会换源**。

**4. 播放报错后自动收掉（#3）**
- 期望：错误提示**照常弹出**；一旦真正起播成功，提示**自动消失**，不需要手动点掉。
- 注意：这条**不改变**判死秒数，起不来的仍然会等满。

**5. 外部播放器长时播放 + 拖动（#8）** —— 用 MX 播一个**非 m3u8 直链**
- 期望：**不再约 10 秒结束**；可正常拖动进度、续传不丢请求头。
- 提醒：投屏用的 RemoteTVBox 与 VLC **没走**这条转发（各有原因），所以只测 MX 这类。

**6. 历史记录（#1 / #4 / #10）**
- 冷启动后**立刻**进历史页 → 期望不再空白（有记录就显示，池没装载完也不丢）；
- 搜索页历史词**长按 → 直接删掉**、旁边的词自动补位；
- 设置页里**不再有**「历史记录」与「导出崩溃日志」两条；条数固定 50。

**7. 线路列表高亮（#6）** —— 首页与订阅管理**各看一次**
- 期望：当前正在用的那条线路**有高亮**；列表滚动/回收后**不残留**高亮。

**8. 续播（#5）** —— 播到中途退出，再进同一集
- 期望：**从头开始播**，画面中央出现「跳转到 xx:xx:xx」；**点它才跳**，点别处或等约 2 s 淡出；**没有**底部 Toast。

**9. 画质显示（#7）** —— 找一个竖屏拍摄、带旋转角的片源
- 期望：显示的宽高与画面实际方向一致（不再显示旋转前的值）。

**10. 缩放（#9）**
- 设置页改缩放 → 新进一个片子应跟着变（**全局生效**）；
- 在播放器里单独调过缩放 → 该影片该线路的**其它剧集**都跟随这个单独值；**设置页再改已不影响它**；
- 换个影片/换条线路 → 回到跟随设置页全局值。
