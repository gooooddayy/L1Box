## ⓪ 本次改了什么

用户复测 E 组后反馈：**换源过渡是「加载中 → 上一线路内容 → 新线路内容」**，中间那一下要去掉。

**成因**：`HomeFragment.loadJar()` 的 `mSilentReload` 分支里调了「收加载态」那一步。它撤掉"加载中"时，
ViewPager 里还是**上一线路**的分类与 adapter（要等新线路的分类数据回来才重建）⇒ 露出旧内容一闪。

**修法**：该分支**保持加载态**，由三个"新内容上屏/结束"的出口来收：
① `initViewModel` 的 `sortResult` 观察者（新分类回来 ⇒ 收加载态 + 重建标签页）
② `startHomeLoad` 候选为空的空态出口 ③ `forceFinishHomeLoad` 超时兜底。
**实质只删了一行调用、加了一行日志。**

**怎么读这份报告**：
- `classes.dex` **+16,588 B** 与 `classes2.dex` **−17,468 B**：R8 在两个 dex 之间**重新分配类**
  （净变化约 **−0.9 KB**，与"删一个调用、加一行日志"相符）；`baseline.prof/.profm` 随类分布更新。
- **类符号 0 增 0 删**；**字符串仅新增 1 条**（本轮的新日志文案），消失 0 ⇒ **零疑点**。
- 其余 3 个 `res/*.xml` 是 **+0 B**（aapt2 重新编号资源 ID），不是功能改动。
