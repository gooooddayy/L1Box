| 项 | 内容 | 为什么 |

| **① 静态推理收口** | 手绑世代账本的修复论证**固化进 `ProtectedInitJar.java` 注释**（触发条件被移除 / 分支可穷举 / `getLoader` 语义反证 / 二层兜底）。**行为零改动** | cf 轮实测条件不成立（配置里没有 `<站点B>`，整轮 1 次手绑 0 次接管）⇒ 用户决定静态收口 |
