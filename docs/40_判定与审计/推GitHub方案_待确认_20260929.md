## 二、🔴 必须先跟你确认的一件事：`tvbox` 到底改到什么程度

**实测结果**（`_gh_upload_L1Box/` 全仓库统计）：

| 形态 | 文件数 | 能否改 |
|---|---|---|
| 包名 `com.github.tvbox.osc` | **279 个文件** | ❌ **绝对不能改** |
| 非包名的纯关键词 `TVBoxOSC` | **0 个文件** | — |

**为什么包名不能改**：`com.github.tvbox.osc` 是**编译进 APK 的包名**。
改它 = 变成一个全新应用 ⇒ **老用户升级装不上**（签名/包名不匹配），桌面会出现两个图标。

**所以"把 tvbox 替换为 box"只能做到**：

| 位置 | 改法 |
|---|---|
| README 显示文字 | ✅ 可全改（你已改了一半） |
| README 里指向 TVBoxOSC 的**链接** | ✅ 可改（去掉外链，改为纯文字） |
| 仓库描述 `box竖屏安卓手机版` | 已是 box，✅ 无需改 |
| 源码里的**包名** | ❌ **必须保留 `com.github.tvbox.osc`** |
| 源码注释里可能出现的 TVBox 字样 | ⚠️ 见下 |

> **我的建议**：只改 **README 的可见文字与链接**，包名一字不动。
> 因为包名在 GitHub 上是公开可见的字符串，但**它是功能性标识，改了App就废了** ——
> 违规风险主要来自"项目名/描述/README 的宣传口径"，而不是包名。

**请你确认**：认同「README 改 + 包名保留」吗？还是你希望连包名一起改（那要接受"老用户无法覆盖安装"）？
