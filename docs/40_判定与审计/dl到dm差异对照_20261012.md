# dl → dm 差异对照（2026-10-12）

## ⓪ 本次改了什么（先看这段）

**一句话：本地字幕改走系统文件选择器（SAF），从而彻底去掉「所有文件访问」权限。**

| # | 文件 | 改了什么 |
|---|---|---|
| 1 | `AndroidManifest.xml` | **移除 `MANAGE_EXTERNAL_STORAGE` 声明**（这是本轮的目的） |
| 2 | `ui/fragment/PlayFragment.java` | 本地字幕：`pickLocalSubtitle()`（`ACTION_OPEN_DOCUMENT`）→ `onActivityResult` → `importSubtitleFromUri()`（按扩展名校验 → 复制到 `getCacheDir()` → **仍调原 `setSubtitle(路径)`**）。删掉 `requestStoragePermission()` 与整段文件浏览器调用 |
| 3 | `check_l1box_compat.sh` | **新增第 6 组（APK 级）**：APK 里不得有「所有文件访问」，且 9 项必需权限一个都不能少 —— ⚠️ 源码删了但**依赖库的 manifest 可能把它合并回来**，所以这条必须落在 APK 上 |
| 4 | `check_l1box_regressions.sh` | 新增 **9 条**源码级断言（清单/播放页都不得再出现「所有文件访问」与文件浏览器库；必须走 SAF；必须按扩展名校验；**下游必须仍是 `setSubtitle(真实路径)`**） |
| 5 | `build_l1box.sh` | 闸门 3 dex 符号 +4（`importSubtitleFromUri` / `REQ_PICK_SUBTITLE` / `isSubtitleName` / 一条提示文案） |

**为什么**：旧的"加载本地字幕"是自研文件浏览器，**从 /sdcard 根目录遍历**，所以 Android 11+ 必须索要
MANAGE_EXTERNAL_STORAGE（最重的权限，还会把用户弹到系统设置页手动开）。换 SAF 后用户自己选文件，
**一分钱权限都不用**；SAF 自 API 19 起可用 ⇒ Android 6+ 全覆盖。下游解析链路**完全没动**（仍是文件路径）。

⛔ **本轮明确不做的三件**（已评估并确认维持现状）：so 改压缩存储（−26.6 MB）、删除迅雷 SDK（−18.8 MB）、minSdk 改 23（Android 6.0）。
评估与依据：`_l1_docs/40_判定与审计/四项优化_值不值得做_20261012.md`
